# Homework 1

Tasks 1–7 are in `src/`, with their pytest tests in `tests/`. Task 6 reads
`task6_read_me.txt`, and Task 7 uses NumPy to calculate an average.

## Setup

From the `cs4300` directory, activate the virtual environment and install
the recorded packages:

    source /coursework/homework1-env/bin/activate
    python3 -m pip install -r homework1/requirements.txt

## Run the tests

From the `cs4300` directory:

    python3 -m pytest homework1/tests -v
